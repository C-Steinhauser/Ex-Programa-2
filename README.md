# Fortuna DesSoft

Este repositório contém o desenvolvimento do **Exercício-Programa 2 (EP2)** da disciplina de **Design de Software**.

O projeto consiste em uma versão para terminal do jogo **Fortuna DesSoft**, um jogo de perguntas e respostas inspirado em programas de televisão, desenvolvido inteiramente em **Python**.

## Funcionalidades

- Sistema de perguntas dividido por níveis:
  - Fácil
  - Médio
  - Difícil
- Sorteio aleatório de perguntas sem repetição
- Sistema de pontuação progressiva
- Sistema de pulos
- Sistema de ajudas
- Validação de entradas do usuário
- Validação da base de perguntas
- Mudança automática de nível
- Encerramento por vitória, derrota ou desistência

## Conceitos utilizados

Durante o desenvolvimento deste projeto foram utilizados diversos conceitos estudados na disciplina, como:

- Funções
- Listas
- Dicionários
- Laços de repetição (`while` e `for`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Modularização do código
- Manipulação de strings
- Sorteio utilizando o módulo `random`

## Organização

O projeto está dividido em três arquivos principais:

- `main.py` — fluxo principal do jogo
- `funcoes.py` — funções auxiliares desenvolvidas ao longo do EP
- `perguntas.py` — base de perguntas utilizada pelo jogo

## Tecnologias

- Python 3

## Objetivo

O objetivo deste projeto foi colocar em prática os conceitos de programação em Python por meio da construção de uma aplicação completa.

Além de atender aos requisitos propostos pela disciplina, foram adicionadas novas perguntas à base e melhorias visuais na interface do terminal.
